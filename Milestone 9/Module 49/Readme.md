#### Authentication vs Authorization
Authentication verifies the identity of a user or entity, while authorization determines what resources or actions the authenticated user is permitted to access or perform. 

In simpler terms, authentication answers the question "Who are you?", and authorization answers the question "What are you allowed to do?".
