### The key categories in folder structure:
1. utilities / utils: small, reusable function or styles that perform specific tasks

2. components: modular, reusable UI elements or pieces of functionality. 
    - UI, Functional, Stateful, Presentational

3. layouts: defines the overall structure of a page, grouping components into sections. 

4. services: files that handle business logic, such as API calls, authentication, or data management.

5. hooks: functions that manage state and lifecycle features in functional component. Examples - useState, useEffect, and custom hooks like `useFetch`

6. state management: Centralized handling of the app's state, often using libraries like Redux and VueX.

7. assets: static resources like images, icons, fonts, and media files

8. styles: css or other styling formats used in design the UI.
